Modelado de datos · dbt + DuckDB

Modelo estrella de un e-commerce real

100 mil órdenes del marketplace brasileño Olist, de CSV crudos a un modelo dimensional listo para cualquier herramienta de BI. Cada tabla está documentada y testeada.

Ver documentación y linaje

El modelo

Dos tablas de hechos con distinto grano y cuatro dimensiones compartidas. Pasá el mouse por una tabla para ver con qué se relaciona.

Capas

Cada capa tiene una sola responsabilidad.

Fuentes8 CSV públicos de Olist, leídos directo por DuckDB sin pasos manuales.
StagingVistas que tipan, renombran y deduplican (por ejemplo, la última reseña de cada orden).
MartsHechos y dimensiones materializados como tablas, con claves de negocio y atributos derivados.

Facturación por categoría

Top 8, órdenes entregadas, en BRL. Sale de fct_order_items + dim_products.

Lo que el modelo permite responder

Puntualidad contra satisfacción: fct_orders.

Tablas y grano

Definir el grano primero es lo que evita duplicar montos al cruzar tablas.

Datos: Olist, Brazilian E-Commerce Public Dataset (2016-2018). Código en GitHub.
